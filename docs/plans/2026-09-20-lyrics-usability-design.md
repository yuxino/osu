# Everyday floating subtitles

The accepted main flow is to start Osu, return to the user's original video app,
and read lyric-style subtitles over that app. Do not require the user to stay in
Osu, add a companion-reading mode, or replace their video player. Keep automatic
input language and Chinese translation as the initial defaults. Preserve the
existing neutral visual style and approved icon.

Make the home introduction describe that flow. Keep service selection and key
configuration prominent in Settings, but put usage details and troubleshooting
in explicit expandable sections. Synthetic checks and numeric diagnostics should
remain available without dominating everyday settings. Hide local-language checks
when using Alibaba and make saved/missing key state visible at the key control.

Verify the actual lyrics painter at regular and largest accessibility sizes with
short, long and mixed-language text. Fix evidenced clipping before optimizing
rendering; preserve readable current text, a subdued previous line, whole-word
English trimming where possible, and Reduce Motion behavior. Render measurements
on Simulator are not phone performance evidence.

Run an extended synthetic stream through the production controller/receiver/client
and retain exact PCM counts, update counts, finalization and local resource data.
Use no live credentials or paid service. Separately inspect normal and large-text
home/settings screens, collapsed/expanded support, cancellation and retained
settings. Build simulator and signed device packages, then commit/push checked
work. The phone is unavailable by user instruction; do not contact or update it.
Real cross-app capture/PiP endurance remains a separate unfinished acceptance gate.
